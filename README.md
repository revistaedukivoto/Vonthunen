# Vonthunen
Simulador interactivo de la teoría de localización agrícola de Von Thünen,
con análisis espacial, costos de transporte, renta del suelo y ordenamiento
territorial.

## Ejecutar localmente

Abrir `index.html` directamente en un navegador moderno. También puede servirse
como sitio estático con cualquier servidor web.

## Despliegue en Vercel

El proyecto no requiere instalación ni proceso de compilación:

- Framework preset: `Other`
- Directorio raíz: raíz del repositorio
- Comando de compilación: ninguno
- Directorio de salida: raíz del repositorio

## Estructura

- `index.html`: interfaz principal.
- `styles.css`: estilos compartidos.
- `js/`: motores económicos, cartográficos, territoriales y de valoración.
- `ARQUITECTURA.md`: arquitectura y documentación técnica.
